# Scripts Directory

Standalone utility and execution scripts:

- `download_mvtec.py`: Download and prepare MVTec AD dataset.
- `train_autoencoder.py`: Script to train Autoencoder.
- `run_patchcore.py`: Script to build memory bank and evaluate PatchCore.
- `evaluate.py`: Benchmark models across multiple categories.
- `app.py`: Gradio / Streamlit interactive web application.
