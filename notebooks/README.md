# Notebooks Directory

This folder is intended for interactive exploration and step-by-step experimentation:

- `01_dataset_exploration.ipynb`: Visualize MVTec AD samples, inspect labels and ground truth defect masks.
- `02_autoencoder_baseline.ipynb`: Train and evaluate a Convolutional Autoencoder for reconstruction error analysis.
- `03_feature_extraction_knn.ipynb`: Extract deep features from CNN backbones and test Nearest Neighbor anomaly scoring.
- `04_patchcore_implementation.ipynb`: Implement patch-level feature extraction, memory bank coreset subsampling, and localization heatmaps.
